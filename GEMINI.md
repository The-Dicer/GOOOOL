# Правила и стандарты проекта GOAL

## 1. Общие требования к стилю и выводу
- **Строгий запрет эмодзи**: Никаких эмодзи в коде, логах, консольных выводах, Telegram-сообщениях и ответах ассистента.
- **Кодировка Windows**: Все скрипты и файлы должны корректно работать с UTF-8 на Windows (`sys.stdout.reconfigure(encoding="utf-8")`).

## 2. Безопасность рабочих путей и процессов
- **Автономный запуск (Планировщик Windows)**:
  - Любой скрипт-точка входа обязан в первых строках устанавливать рабочий каталог на корень проекта:
    `PROJECT_DIR = os.path.dirname(os.path.abspath(__file__)); os.chdir(PROJECT_DIR)`
  - При создании или обновлении задач в Планировщике Windows всегда явно указывать `WorkingDirectory`.

## 3. Изоляция операторов и персональная рассылка
- Каждый оператор получает персональный отчет, содержащий только его матчи и количество игр.
- Для каждого оператора создается отдельный файл ключей `stream_keys_YYYY-MM-DD_HH-MM_{operator}.txt`.
- Кнопка Telegram WebApp калькулятора пакует в URL-хэш только матчи конкретного оператора.
- Если у оператора нет матчей в пакете, сообщение ему не отправляется.

## 4. Разделение тестового и боевого режимов
- **Тестовый режим**:
  - Канал Rutube: личный канал (ID 20432577, очистка cookie `scope`).
  - Footballista: ссылки на трансляции НЕ вставляются.
  - Перед переходом в боевой режим тестовые стримы, ключи и записи базы обязательно зачищаются.
- **Боевой режим**:
  - Канал Rutube: официальный канал лиги AFL Moscow (`77095292`).
  - Footballista: прямая вставка ссылок на трансляции под токенами операторов.

## 5. Генерация обложек (AFL Graphics)
- Перед выбором матча очищать инпут.
- Обязательная валидация превью перед снятием скриншота: превью должно содержать имя команды текущего матча, чтобы исключить захват предыдущей обложки.

## 6. Хостинг WebApp
- Калькулятор размещается строго на официальном GitHub Pages:
  `https://the-dicer.github.io/GOOOOL/webapp/calculator.html`
- Не использовать сторонние сырые прокси (githack и др.), блокирующие прямые переходы заглушками.
