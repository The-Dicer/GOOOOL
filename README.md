# GOAL 3.2 — Автоматизация трансляций AFL & Footballista

Комплексная система автоматизации рутины оператора спортивных трансляций лиги AFL: сбор расписания, генерация обложек, создание трансляций на Rutube, экспорт RTMP-ключей, фоновый автопилот и финансовый учет.

## Основные возможности

1. **Сбор расписания с Footballista**
   - Автоматический сбор назначенных игр на предстоящий уикенд (пятница, суббота, воскресенье).
   - Поддержка расширенной выборки (до 30 матчей из всех доступных туров без ограничений по датам).

2. **Генерация и нормализация обложек (AFL Graphics)**
   - Выбор лиги и турнира в сервисе AFL Graphics.
   - Автоматическое назначение цвета стадиона по ключевым словам из базы стадионов.
   - Принудительная нормализация разрешения обложки под эталонный Full HD (1920x1080, 16:9) без черных полос.

3. **Публикация на Rutube Studio**
   - Создание трансляций с автостартом, заполнением заголовков, описаний и загрузкой обложек.
   - **Поддержка прав модератора:** автоматическое переключение на модерируемый канал лиги (ID `77095292`) перед созданием трансляций.
   - Извлечение URL трансляции, сервера и RTMP-ключа.

4. **Интеграция с карточками матчей Footballista**
   - Автоматическая привязка готовых ссылок Rutube к карточкам матчей в панели управления Footballista.

5. **Фоновый автопилот и Планировщик Windows (Task Scheduler)**
   - Мониторинг появления расписания по пятницам и субботам в фоновом режиме.
   - Создание трансляций без необходимости держать открытым графический интерфейс.
   - Умное закрытие выходных: когда все игры уикенда созданы, проверки отключаются до следующей недели.

6. **Оповещения в Telegram и мобильный WebApp-калькулятор**
   - Моментальный отчет со ссылками на созданные матчи и прикрепленным файлом `stream_keys.txt`.
   - Интерактивный Telegram WebApp: расчет оплаты оператора по индивидуальной ставке, возможность исключать неоплаченные матчи прямо на смартфоне и накопительный финансовый архив за месяц (100% приватность в браузере телефона).

7. **Экстренный отчет за произвольный период (Failsafe)**
   - Формирование отчета и ссылки на калькулятор для любых нестандартных дат, праздничных туров и разовых смен.

8. **Безопасная очистка канала Rutube (`scripts/cleanup_rutube_now.py`)**
   - Удаление исключительно пустых запланированных черновиков (`wait`).
   - Строгая защита завершенных видео, записей прошедших матчей и текущих прямых эфиров.
   - Выбор очищаемого канала: личный канал оператора или официальный канал лиги.

## Инструкция по запуску

### Вариант 1. Запуск скомпилированного приложения (`.exe`)
1. Поместите файл `GOAL 3.2.exe` в отдельную папку.
2. Запустите его.
3. Нажмите кнопку **«1. Запустить Chrome»** и войдите в свои аккаунты на сайтах:
   - [Footballista](https://footballista.ru/admin/games) (раздел «Игры»)
   - [AFL Graphics](https://afl-graphics.vercel.app/igraphics/video)
   - [Rutube Studio](https://studio.rutube.ru/)
4. Нажмите **«2. Собрать расписание»**, выберите нужные матчи и нажмите **«ОПУБЛИКОВАТЬ»**.

### Вариант 2. Запуск из исходного кода (Python)
1. Установите зависимости:
   ```bash
   pip install customtkinter playwright pillow requests
   python -m playwright install chromium
   ```
2. Скопируйте файл конфигурации:
   ```bash
   cp config.example.json config.json
   ```
3. Запустите графический интерфейс:
   ```bash
   python main.py
   ```

## Консольные команды (CLI)

Для управления без GUI используется `auto_runner.py`:

- **Проверка расписания без создания стримов:**
  ```bash
  python auto_runner.py --check-only
  ```
- **Однократная проверка и создание новых стримов:**
  ```bash
  python auto_runner.py
  ```
- **Тест отправки сообщения в Telegram:**
  ```bash
  python auto_runner.py --test-tg
  ```
- **Автоматическое определение Telegram Chat ID:**
  ```bash
  python auto_runner.py --get-chat-id
  ```
- **Формирование Failsafe-отчета за период:**
  ```bash
  python auto_runner.py --report 01.09.2026 15.09.2026
  ```
- **Безопасная очистка Rutube:**
  ```bash
  python scripts/cleanup_rutube_now.py
  ```
