# ⚽ GOAL (Global Operator Automation League)

![GOAL Interface](https://github.com/user-attachments/assets/0067d2a2-ae65-4306-940b-2f72842818ba)

**GOAL** — это приложение для полной автоматизации рутинных задач оператора спортивной лиги. Программа берет на себя всю монотонную работу по подготовке трансляций матчей, объединяя в себе сразу несколько платформ.

## ✨ Ключевые возможности

*   **Автоматический сбор расписания:** Парсит актуальное расписание предстоящих матчей с сайта [Footballista](https://footballista.ru/).
*   **Генерация превью:** Самостоятельно создает стильные обложки для каждого матча через сервис [AFL Graphics](https://afl-graphics.vercel.app/igraphics/video).
*   **Интеграция с Rutube:** 
    *   Автоматически создает новые трансляции.
    *   Заполняет названия и описания по шаблону.
    *   Загружает сгенерированные обложки (с учетом последних обновлений платформы).
    *   Включает функцию автостарта эфира.
*   **Обратная синхронизация:** Возвращает готовые ссылки на созданные трансляции Rutube обратно в карточки матчей на платформу Footballista.
*   **Удобный экспорт ключей:** Сохраняет все RTMP-ключи и серверные URL трансляций в удобный текстовый файл для быстрого запуска стримов через OBS Studio или vMix.

## 🚀 Инструкция по запуску

### Требования
* На вашем компьютере должен быть установлен браузер **Google Chrome**.

### Шаги для старта

1. **Скачайте программу:** Загрузите последний релиз (`GOOAAL.exe`) и поместите его в отдельную папку на вашем ПК (в этой же папке будут сохраняться ключи трансляций и логи).
2. **Запустите `GOOAAL.exe`**. Откроется графический интерфейс программы.
3. **Авторизация (Шаг 1):** Нажмите кнопку **"1. Открыть Chrome..."**. Откроется окно браузера. В нем необходимо вручную авторизоваться на трех площадках:
    *   [Footballista](https://footballista.ru/admin/games) (перейдите на вкладку "Игры")
    *   [AFL Graphics](https://afl-graphics.vercel.app/igraphics/video)
    *   [Rutube Studio](https://studio.rutube.ru/) (убедитесь, что выбран правильный канал для трансляций)
4. **Запуск (Шаг 2):** После успешной авторизации вернитесь в окно программы и нажмите кнопку запуска.
5. **Контроль:** Следите за процессом во встроенном окне логов программы. Скрипт пошагово будет отчитываться о выполнении задач.
