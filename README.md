# GOAL 2.1 (Global Operator Automation League)

![GOAL Interface](https://github.com/user-attachments/assets/0067d2a2-ae65-4306-940b-2f72842818ba)

GOAL — это десктопное приложение для автоматизации рутинных задач оператора спортивной лиги. Программа объединяет в себе парсинг расписания, генерацию графики и создание трансляций, управляя процессом через графический интерфейс.

## Архитектура и основной пайплайн

Программа работает в связке с браузером Google Chrome через Playwright (использует текущие сессии и авторизацию пользователя).

1. Сбор данных: Парсит карточки матчей на предстоящие выходные с сайта Footballista.
2. Генерация графики: Подключается к AFL Graphics, выбирает нужный паттерн, лигу и автоматически подбирает цвет обложки в зависимости от стадиона.
3. Создание трансляций на Rutube: Автоматически создает трансляции, заполняет название и шаблонное описание, загружает сгенерированную обложку и включает "Автоматический запуск". Встроен механизм автоповтора (до 3 раз) на случай нестабильной работы площадки.
4. Возврат ссылок: Вставляет ссылки на готовые трансляции Rutube обратно в карточки матчей на Footballista.
5. Экспорт ключей: Сохраняет RTMP-серверы и ключи для OBS в отдельный текстовый файл (например, stream_keys.txt).

## Интерфейс приложения

Приложение состоит из боковой панели управления и четырех функциональных вкладок.

### Боковая панель (Управление)
* 1. Запустить Chrome: Открывает специальный экземпляр браузера (с включенным портом отладки).
* 2. Собрать расписание: Запускает парсинг матчей с Footballista.
* ОПУБЛИКОВАТЬ / СТОП: Запуск основного пайплайна для выбранных матчей или его экстренная остановка.

### Вкладка "Матчи"
Содержит список всех найденных матчей с возможностью выбора конкретных игр для публикации (чекбоксы). В нижней части расположена консоль логов, где в реальном времени отображается статус работы скрипта.

### Вкладка "Настройки"
* Паттерн графики: Выбор дизайна ("Автовыбор", "1", "2").
* Лига: Выбор лиги для AFL Graphics.
* Цвет по умолчанию: Номер цвета, который будет использован, если стадион не найден в базе.
* Шаблон описания: Редактор текста, который будет прикрепляться к видео на Rutube.
* Настройки автоматически сохраняются в файл config.json.

### Вкладка "Цвета стадионов"
Динамическая база данных привязки названий стадионов к номерам цветов для AFL Graphics (например, "труд" -> "3"). Позволяет добавлять новые и удалять существующие стадионы прямо из интерфейса.

### Вкладка "Дебаг"
* Тестовый режим: Выполняет весь пайплайн, но не публикует итоговую ссылку обратно на сайт Footballista.
* Сбор последних 30 матчей: Игнорирует проверку даты и собирает последние прошедшие матчи для тестирования парсера, если на текущую неделю игр нет.

## Инструкция по запуску

1. Скачайте последний релиз программы (GOOAAL.exe) и поместите его в отдельную пустую папку на вашем ПК (здесь будут сохраняться логи, ключи и конфиг).
2. Убедитесь, что у вас установлен браузер Google Chrome.
3. Запустите GOOAAL.exe.
4. В боковой панели нажмите "1. Запустить Chrome...".
5. В открывшемся браузере авторизуйтесь на следующих площадках:
   - Footballista (перейдите на вкладку "Игры")
   - AFL Graphics
   - Rutube Studio (убедитесь, что выбран правильный канал)
6. Вернитесь в приложение, нажмите "2. Собрать расписание", выберите нужные матчи и нажмите "ОПУБЛИКОВАТЬ".
