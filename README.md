### 🎯 Что делает GOAL? (Базовый функционал для новичков)

Программа полностью автоматизирует рутину оператора лиги:

1. **Собирает актуальное расписание** предстоящих матчей с сайта Footballista.
2. **Генерирует стильные обложки** для каждого матча через сервис AFL Graphics.
3. **Создает и настраивает трансляции на Rutube** (заполняет названия, описания, загружает обложки и включает автостарт).
4. **Возвращает ссылки** на готовые трансляции обратно в карточки матчей на Footballista.
5. **Сохраняет RTMP-ключи** в удобный текстовый файл для запуска стримов.

### Инструкция по запуску:
1. Скачайте файл GOOAAL.exe ниже и положите в отдельную папку.
2. Запустите его.
3. Нажмите кнопку "1. Открыть Chrome..." и залогиньтесь во все сервисы.
4. Откройте [Footballista](https://footballista.ru/admin/games) на вкладке 'Игры', [AFL Graphics](https://afl-graphics.vercel.app/igraphics/video), [Rutube](https://studio.rutube.ru/) с правильным аккаунтом.
5. Запустите.
6. Следите за логами
